# Clinical Metrics Regression Analysis

## Описание проекта
Данный проект представляет собой исследование в области анализа медицинских данных и статистического моделирования. 
Основная цель — разработка многофакторной скоринговой модели для прогнозирования клинической оценки тяжести состояния пациентов на основе базовых физиологических показателей.

Проект демонстрирует применение метода наименьших квадратов (OLS) для извлечения непрерывного индекса тяжести с его последующей математической дискретизацией для решения задачи классификации.

## Стек технологий
* **Язык:** Python
* **Библиотеки:** `pandas`, `numpy`, `scikit-learn`, `statsmodels`, `matplotlib`, `seaborn`
* **Среда:** Jupyter Notebook для исследовательского анализа (EDA), Python-скрипты для итогового пайплайна.

## Данные
В работе анализируется набор данных из 305 записей со следующими клинико-лабораторными предикторами:
* Возраст (`Age`)
* Температура тела (`Temperature`)
* Уровень сатурации кислорода (`SatO2`)
* Креатинин (`Ctreating`)
* С-реактивный белок (`SRB`)
* Фибриноген (`fibrinogen`)
* Нейтрофилы (`Neutral`)

**Целевая переменная:** Клиническая оценка тяжести состояния (`Клин_Оценка`): 0 (легкая), 1 (средняя), 2 (тяжелая).

## Методология
1. **Предобработка данных:** Заполнение пропусков, кодирование категориальных переменных, добавление константы (интерсепта) для линейной модели.
2. **Борьба с утечкой данных:** Строгое разделение на обучающую (70%) и тестовую (30%) выборки (Hold-out).
3. **Моделирование:** Построение множественной линейной регрессии (`statsmodels.OLS`) для получения непрерывного скорингового балла.
4. **Дискретизация:** Конвертация непрерывных предсказаний регрессии в классы диагнозов с помощью жесткого округления (clipping).
5. **Оценка качества:** Использование метрики Accuracy на отложенной выборке для проверки обобщающей способности алгоритма.

* **Корреляционные матрицы (Пирсон и Спирмен):** Стандартная матрица и ранговая матрица Спирмена (устойчивая к выбросам) помогли диагностировать мультиколлинеарность признаков и выделить наиболее сильные предикторы.

*(Пример графиков можно посмотреть в папке `images/`)*

## Ключевые результаты
* **Точность модели:** Итоговая точность предсказания диагноза составила **77.5%** на обучающей выборке и **82.6%** на тестовой. Отсутствие падения метрики доказывает устойчивость модели к переобучению.
* **Анализ предикторов:** Анализ p-value выявил высокую мультиколлинеарность исходных данных. Алгоритм статистически подтвердил, что наиболее надежным линейным предиктором тяжести состояния в данном наборе является уровень С-реактивного белка (СРБ).
